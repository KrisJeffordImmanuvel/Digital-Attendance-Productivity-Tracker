📝 Wireframe notes

Purpose

A simple to-do list for study tasks, linked to subjects and to the focus timer, with a daily goal.

Key elements

  • Daily goal progress (minutes + tasks)
  • Quick-add task field
  • Filter chips: To do / Today / Done
  • Task rows: checkbox, subject, due date, priority, Pomodoros done/estimated
  • ▶ Focus starts the timer for that task

Interactions

  • Add → new task (full form: subject, due date, priority)
  • Checkbox → mark done
  • ▶ Focus → Focus timer
