📝 Wireframe notes

Purpose

A Pomodoro timer (Francesco Cirillo's technique) that saves each focus block, linked to a subject or task, so study time can be measured.

Key elements

  • Mode tabs: Focus 25 / Short break 5 / Long break 15
  • Large countdown with Pomodoro progress dots
  • Task / subject selector
  • Start / Pause and Reset
  • Today's summary versus daily goal

Interactions

  • Start toggles to Pause (the demo counts down)
  • Finished block → saved as a FocusSession and break starts
  • Analytics → Productivity analytics

Linked features

ST-7, ST-9, ST-11 (see 04-features-and-system-flow.md)
