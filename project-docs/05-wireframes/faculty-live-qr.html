📝 Wireframe notes

Purpose

Projected in class. Shows a QR that changes every 10 seconds, so a forwarded photo is useless, plus a live present count.

Key elements

  • Large QR placeholder that redraws every 10 s, with countdown bar
  • Present X / Y counter (live via WebSocket)
  • Rejected-scan and manual-mark counts
  • Latest scans list with rejection reason
  • Mark manually (reason required) and End session

Interactions

  • The demo QR pattern and countdown refresh every 10 s
  • End session → absentees auto-marked → Class report
  • Full screen hides everything except QR + count

FA-2, FA-3, FA-4, FA-8 (see 04-features-and-system-flow.md)
