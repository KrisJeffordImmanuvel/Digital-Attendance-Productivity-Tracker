📝 Wireframe notes

Purpose

Admins add, import, edit and deactivate users, and approve or reject device-change requests.

Key elements

  • Search and role / class filters
  • User table with device status (bound / change requested / not registered)
  • Add user (teal) and Import CSV with error report
  • Device change requests: Approve / Reject

Interactions

  • Approve → old device unbound, student binds the new phone at next login
  • Edit → user form (future)
  • Import CSV → shows rows added / failed

Linked features

AD-1, AD-2, AD-4 (see 04-features-and-system-flow.md)
