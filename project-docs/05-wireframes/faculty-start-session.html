📝 Wireframe notes

Purpose

Faculty pick the class, subject and period, then start a session. It shows which anti-proxy checks are active before starting.

Key elements

  • Class / subject / period / room selectors (only the faculty member's own subjects)
  • Status strip: QR rotation, geofence, device binding
  • Start session (orange, main action)
  • Today's timetable and recent sessions with rejected-scan counts

Interactions

  • Start session → Live QR screen
  • Sidebar → Live QR, Class report
