📝 Wireframe notes

Purpose

Marks attendance by scanning the faculty's rotating QR. The server checks the token, geofence, device and duplicates, and the result is shown clearly.

Key elements

  • Camera placeholder with a scan frame
  • Permission and device status (location is used only during the scan)
  • Success state: subject, time, the 4 checks passed, updated %
  • Failure state: one clear reason plus a next step

Interactions

  • Use the grey switcher to preview the Scanning / Success / Failure states
  • Success → Back to Home
  • Failure → Scan again / Request device change
