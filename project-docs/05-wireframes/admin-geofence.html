📝 Wireframe notes

Purpose

Admins define where on campus scans are allowed (one or more circular zones) and set the attendance rules used for validation.

Key elements

  • Map placeholder with zone circles
  • Zone list: name, latitude, longitude, radius; add / edit zones
  • Rules: minimum %, QR rotation, grace period, device-change limit
  • Save settings (teal), Test my location

Interactions

  • Save → applies to new scans immediately and is logged
  • Test my location → shows whether this device is inside a zone
