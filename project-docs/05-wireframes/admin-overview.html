📝 Wireframe notes

Purpose

A college-wide snapshot for admin and management: overall attendance, students at risk, live sessions and pending tasks.

Key elements

  • KPI tiles (overall %, below 75%, sessions today, pending requests)
  • Placeholder department chart and table
  • Device-change requests with Review
  • Live sessions list
  • Shortcut to geofence settings, Export institution report

Interactions

  • Review → Manage users (device requests)
  • Geofence card → Campus geofence settings
  • Export → CSV / PDF institution report
