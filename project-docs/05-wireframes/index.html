Venture Ideation · Planning & Design · Wireframe v0.1

Digital Attendance and Productivity Tracker for Students

Team: Venuprasadd M.K · Kris Jefford I · Sujith S · Vignesh K · Ajin S.S

How to use

Click any screen below. Inside a screen, buttons, tabs and bottom / side navigation are clickable, and ← All screens brings you back here. The right-hand Wireframe notes explain each screen's purpose.

Style rules

  • Greyscale everywhere (it's a wireframe, not the final design).
  • Teal #0F4C5C = primary button
  • Orange #E36414 = the single most important action on key screens
  • Warnings use ⚠ + text labels, never colour alone.

Frames

Student screens: mobile phone frame 390 × 844.
Faculty and admin screens: desktop browser frame.
All names and numbers are sample data.

Student · mobile

Main flow: Login → Home → Scan QR → (Focus timer / Tasks) → Analytics

01

Login

Role tabs, roll number + password, device-binding notice.

02

Student Home

Overall and subject %, 75% warning, today's classes.

03

Scan QR

Camera placeholder with Scanning, Success and Failure states.

04

Attendance History

Every class with status, filters, report a problem.

05

Focus Timer

Pomodoro countdown linked to a task or subject.

06

Tasks

To-do list with subjects, due dates and a daily goal.

07

Productivity Analytics

Summary tiles and placeholder charts.

08

Profile

Registered device, alert and timer settings, log out.

Faculty · desktop

Main flow: Start Session → Live QR → End session → Class report

09

Start Session

Pick class, subject and period; see active anti-proxy checks.

10

Live QR

QR that changes every 10 s, live present count, manual mark.

11

Class Report

Per-student %, below-75% rows highlighted, export CSV.

Admin · desktop

Setup and monitoring for the whole college

12

Overview

KPI tiles, department table, live sessions, requests.

13

Manage Users

User table, CSV import, device-change approvals.

14

Campus Geofence

Campus zones on a map placeholder and attendance rules.
