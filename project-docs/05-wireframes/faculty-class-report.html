📝 Wireframe notes

Purpose

Lets faculty see each student's attendance % for a subject, spot students below 75%, and export the report without retyping.

Key elements

  • Class / subject / date-range filters and a below-75% toggle
  • Summary tiles: students, average, below 75%, sessions held
  • Table sorted by roll number or %; rows below 75% highlighted with a label (not colour alone)
  • Export CSV (teal), Export PDF, Notify students below 75%

Interactions

  • Export CSV → downloads exactly the rows shown
  • Click a student → their session-by-session record (future)
  • Notify → sends a below-75% alert to those students
