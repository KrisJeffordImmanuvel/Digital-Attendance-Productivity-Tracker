📝 Wireframe notes

Purpose

The student's main dashboard. It answers "Where do I stand?" at a glance and leads to today's main action: scanning in class.

Key elements

  • Overall attendance % ring
  • 75% warning card with classes needed to recover
  • Subject-wise % bars; below-75% subjects carry a text label, not just a shade
  • Today's classes with status; the current class shows a Scan QR button
  • Today's focus-goal progress

Interactions

  • Scan QR (orange) → Scan screen
  • History → Attendance history
  • Focus goal card → Focus timer
  • Avatar → Profile

Linked features

ST-4, ST-5, ST-9, ST-12 (see 04-features-and-system-flow.md)
